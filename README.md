# deca

Chapter timeline and official deadlines page for a Collegiate DECA
chapter's ICDC trip: chapter milestones plus DECA Inc.'s official
registration/deadline dates, as two tables on a single static page.

**Live site:** https://vm2027.github.io/deca/

`index.html` is the entire site, served directly from `main` with no
build step. There is no data pipeline, no CI, and (deliberately) no
tooling — see `CLAUDE.md` for the repo's conventions and the review
process for changes.
